# 复习清单

按艾宾浩斯遗忘曲线（FSRS 算法，Anki 现任默认算法）安排复习计划的个人任务清单。纯静态 PWA，手机添加到主屏幕即用。

## 当前形态

- 代码永久保存在 GitHub 仓库：`xiajintao12-arch/review-list`
- 访问地址：https://review-list.app.workbuddy.host/
- **数据存在你打开它的那台设备的浏览器里**（localStorage），不依赖任何后端
- 备份：更多功能页底部「导出备份 / 导入备份」

## 功能

- 今日 List：打开就是当天该复习什么，勾选即完成
- 添加任务：底部输入，标题即行动（必填）；可加附件（≤2MB）、可设 DDL
- DDL 任务：自动排在列表最后；只在 DDL 当天计入完成率
- 复习打分：忘了 / 难 / 好 / 简单，FSRS 据此排下次复习日（默认勾选 = "好"）
- 科学调参：每个任务可调「目标记住率」0.70–0.97（长期记忆 0.85 / 标准 0.90 / 考前冲刺 0.95），改完立即按遗忘曲线重排
- 更多功能：近 7 天完成个数、完成百分数两张折线图；未来 14 天计划；任务管理与删除；导出/导入备份

## 重要提醒

- **数据只在本机**：换手机、清理浏览器缓存会丢数据 → 定期「导出备份」，把 JSON 存网盘或发给自己
- **改前端后要重新部署**，并且必须把 `sw.js` 里的 `CACHE` 版本号 +1，否则手机端会看到旧版

## 关于"永久链接"（实测结论，2026-09-29）

在国内网络下实测的可达性：

| 平台 | 能否访问 |
|---|---|
| vercel.app | ❌ 被拦（DNS 污染） |
| github.io（GitHub Pages） | ❌ 被拦 |
| supabase.co | ❌ 被拦 |
| netlify / Cloudflare 部分节点 | ❌ 被拦 |
| workbuddy.host（当前托管） | ✅ 可访问 |
| 腾讯云 | ✅ 可访问 |

**想真正做到长期可控 + 跨设备同步，推荐路径**：
1. 买一个自己的域名（.top/.xyz 二三十元一年，境外托管不用备案）
2. 绑到已建好的 Vercel 项目上（代码已适配，`api/state.js` + Vercel Blob 云存储已就绪）
3. 或者走腾讯云开发 CloudBase（国内节点最稳，需实名认证）
